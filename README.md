# Gerador de Tickets FVP (página publicada)

Acesse a página pelo GitHub Pages e arraste a base do ciclo (.csv ou .xlsx).
A base é processada no seu navegador: **nenhum dado é enviado para a internet**.

Este repositório contém só a página publicada (`index.html`). Ela é gerada e atualizada
automaticamente a partir do repositório do projeto; não edite aqui.
